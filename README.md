# Planboard

Planboard 是一个 [Obsidian](https://obsidian.md) 日历与待办插件。它在主区域提供一个「月 / 周」双模式日历，在侧边栏提供一个小月历加当日待办列表，所有数据都以纯 Markdown 笔记的形式存在你的仓库里 —— 可读、可改、始终是你自己的。

## 功能

- **月视图与周视图** —— 在主视图顶部栏一键切换。
- **侧边栏小月历** —— 紧凑的月历网格，下方跟着选中日期的待办列表，不用离开当前笔记就能查看日程。
- **按天管理待办** —— 直接在日历格子上添加、编辑、删除、勾选任务。
- **三级优先级** —— 高 / 中 / 低，每级有独立的色条，颜色可自定义。
- **右键菜单** —— 在任意任务上右键：复制、粘贴、移到下一天、移到下一周。
- **纯 Markdown 存储** —— 每个时间段就是仓库里一篇普通笔记，没有数据库，不存在锁定。
- **存储粒度可选** —— 按月、按周或按年生成笔记文件。
- **中国法定节假日** —— 已内置 2026 年法定节假日，显示节日名称和特殊背景。
- **外观可调** —— 周末高亮、节假日标识、任务数量角标、优先级颜色、背景图及透明度。
- **周起始日可选** —— 周一或周日。
- 桌面端与移动端均可使用。

## 安装

### 从社区插件市场安装

尚未上架，正在提交中。上架后可在 **设置 → 第三方插件 → 浏览** 中搜索安装。

### 手动安装

1. 从 [最新 Release](../../releases/latest) 下载 `main.js`、`manifest.json`、`styles.css`。
2. 在你的仓库中新建文件夹 `<你的仓库>/.obsidian/plugins/planboard/`。
3. 把这三个文件放进该文件夹。
4. 重启 Obsidian，然后在 **设置 → 第三方插件** 中启用 **Planboard**。

## 使用

### 视图

插件注册了两个视图：

- **日历主视图** —— 位于中间区域。顶部栏按钮可切换月 / 周模式，左右箭头切换上一个 / 下一个时间段，**今日** 按钮跳回当前日期，**+** 按钮新建任务。
- **侧边栏视图** —— 位于右侧边栏的小月历。点击任意日期，下方即显示该日待办。

点击左侧功能区的日历图标，可同时打开这两个视图。

### 管理任务

- 点击日期格子或 **+** 按钮，输入标题和优先级即可新建任务。
- 点击任务前的复选框可标记完成。
- 点击任务本身打开编辑弹窗。
- 在任务上右键唤出菜单：**复制**、**粘贴**、**移到下一天**、**移到下一周**。

### 数据存储

任务以 Markdown 笔记形式保存在设置里的存储路径下（默认为 `日程/`），文件名取决于你选择的存储粒度：

| 存储粒度 | 示例文件 |
| --- | --- |
| 按月 | `日程/2026-06.md` |
| 按周 | `日程/2026-W23.md` |
| 按年 | `日程/2026.md` |

笔记内容形如：

```markdown
---
type: schedule
period: 2026-06
generated: true
---

## 2026-06-15

- [ ] 写周报 <!-- k3f9a2 high 2026-06-15T09:12:00.000Z 2026-06-15T09:12:00.000Z -->
- [x] 预订会议室 <!-- m8b1c4 low 2026-06-14T11:30:00.000Z 2026-06-15T08:02:00.000Z -->
```

这些笔记你可以像普通笔记一样阅读和编辑。唯一不要动的是每行任务末尾的 HTML 注释 —— 里面存着任务 ID、优先级和时间戳。删掉或改写它，这个任务就会失去身份标识。

## 设置项

**数据设置**

| 设置项 | 说明 |
| --- | --- |
| 存储粒度 | 按月 / 周 / 年生成笔记文件。 |
| 存储路径 | 笔记存放目录，可输入关键字搜索，也可点文件夹按钮浏览选择。 |
| 已完成显示 | 「划掉保留」始终显示已完成并可手动隐藏；「隐藏」默认隐藏已完成，可切换显示。 |
| 周起始日 | 周一或周日。 |

**外观设置**

| 设置项 | 说明 |
| --- | --- |
| 优先级颜色 | 三个优先级各自的色条颜色，附重置按钮。 |
| 背景图片 URL | 主页日历的背景图，支持 `https://` 链接或 `local://` 路径，留空则不使用。 |
| 背景图透明度 | 背景图显示强度，0 为不可见，1 为完全显示。 |
| 显示周末高亮 | 周六 / 周日使用不同颜色标识。 |
| 显示节假日标识 | 节假日显示节日名称和特殊背景。 |
| 显示任务数量角标 | 在日期格子上显示该日待办数量。 |

## 开发

```bash
git clone https://github.com/cmr0122/obsidian-planboard.git
cd obsidian-planboard
npm install
npm run dev     # 监听模式，改动后自动重新构建 main.js
npm run build   # 类型检查并产出生产构建
```

`npm run dev` 会把 `main.js` 输出到项目根目录。调试时可以把项目文件夹直接放进 `<你的仓库>/.obsidian/plugins/`，或者软链接过去。**文件夹名必须与插件 ID 一致，即 `planboard`。**

目录结构：

```
src/
  main.ts              插件入口，视图注册
  types.ts             共享类型与默认设置
  constants.ts         文案标签、优先级配置
  settings.ts          设置面板
  services/            数据层（读写 Markdown 笔记）
  views/               主日历视图、侧边栏视图、周视图
  components/          网格、日期格子、任务条目、视图切换器
  modals/              新建 / 编辑任务弹窗、文件夹选择器
  utils/               日期工具、节假日表、剪贴板
```
